Throttle mapv = ((thr − THR_MIN) / (32767 − THR_MIN)) × V_MAX; v = 0 if thr ≤ THR_MIN—Monotonic map that starts from zero at the edge of the deadband, so there is no jump in speed

Safety

SymbolProposed ValueUnitsRationale
CMD_TIMEOUT90msNo valid command for this long puts the car in ERROR (brake and hazards). Leaves margin for the 100 ms fault-response requirement
CMD_KEEPALIVE50 (minimum spacing 10)msUnchanged state is resent at this rate, and changes are sent at most every 10 ms
FAULT_RECOVERYNext valid command—An out-of-range value invalidates the stored command. Driving resumes only when a new valid command arrives
SAFETY_POLL5msSafety and blinker check rate. Link loss is detected within about 95 ms
BUTTON_DEBOUNCE30msMinimum time between accepted presses of the self-test button
SELF_TEST_EXITDouble press within 350msA single press enters self-test (brake and hazards). A double press exits it
